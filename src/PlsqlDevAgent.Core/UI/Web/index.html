Settings

LLM Server

Server: Base URL
OpenAI compatible endpoint, e.g. http://llm-server:8000/v1
Server: API Key
Optional. Stored encrypted for your Windows user.
Server: Model
Use Test to check the connection and list the available models.
Server: Temperature
Server: Max Tokens
Maximum length of one answer.
Server: Context Window
Context size of the model in tokens (token meter and automatic compaction).
Server: Detect Context Window
Server: Compact At
Summarize older messages when the conversation uses this percentage of the context window (0 = never).
Server: Timeout
Request timeout in seconds.
Server: Extra Request JSON
Merged into every request, e.g. {"top_p": 0.95}.
Server: Use System Proxy
Server: Trusted Certificates
Only needed if the server's HTTPS certificate is not trusted by Windows (the connection test then shows the thumbprints): SHA-1 or SHA-256 thumbprint of the server certificate or of the CA that issued it; several separated by ;.
Server: Request Usage

Instructions & Rules

Instructions: System Prompt
The agent's base instructions: role, way of working, answer style. The rules for tools, modes and the task list are always added.
Instructions: Company Rules
Markdown file or folder with your company rules and coding / naming conventions, e.g. on a network share so the whole team uses the same rules (%VARIABLES% allowed). Files in the plug-in's rules folder are always loaded as well.
Instructions: Personal Instructions
Your own additions, e.g. preferred answer language. Project rules belong into AGENTS.md in the project folder.

Agent

Agent: Project Folder
Optional. Enables the file tools, AGENTS.md and .plsqlagent/commands.
Agent: Custom Commands
One per line: /name = prompt. $ARGUMENTS is replaced by the text after the command.
Agent: Max Steps
Maximum number of model turns per round.
Agent: Auto Continue
Agent: Max Auto Continues
How often per request the agent may be continued automatically.
Agent: Sub-task Max Steps
Model turns a helper agent (run_subtask) may use for its research.
Agent: Sub-task Model
Model for helper agents (run_subtask), e.g. a smaller, faster model of your server. Empty = the main model.
Agent: Max Query Rows
Agent: Compiler Warnings
Agent: Suggest Objects After @

Safety: Protected Connections
The agent is read-only on connections matching these patterns (user@database or database, wildcards * and ?, separated by ;). Can be unlocked per session in the chat header.

Local Data

Local data: Save Chat History
Local data: Saved Content
What a saved chat contains. Without tool results: query results, file and object contents and attachments are left out (the agent's answers are kept as written and may quote data).
Local data: Keep Chats (days)
Saved chats and prompt history entries older than this are deleted. 0 = keep until deleted manually.
Local data: Keep Backups (days)
Source backups (Restore previous) older than this are deleted. 0 = keep.
Local data: Keep Log (days)
Log entries older than this are deleted (the log contains SQL statements of the agent). 0 = keep; the log is limited to 2 × 2 MB.
